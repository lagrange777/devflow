# Сценарий демонстрации Devflow

Сценарий на **4–5 минут**. Заранее открой [DEMO.md](https://github.com/lagrange777/devflow/blob/main/DEMO.md), [PR #2](https://github.com/lagrange777/devflow/pull/2), [CI](https://github.com/lagrange777/devflow/actions/runs/39226888249) и [релиз](https://github.com/lagrange777/devflow/releases/tag/v0.1.0).

## 1. Задача — 30 секунд

Покажи описание проекта:

> «Я автоматизирую повторяющийся цикл разработки Go-приложений. Пользователь описывает задачу, а Devflow последовательно проводит её через требования, тесткейсы, спецификацию, код, PR, ревью и релиз. Реальный пример — улучшение собственной команды `doctor`: проверять Git и Docker до платного обращения к AI».

## 2. Этапы и участие AI — 1,5 минуты

Открой `development-evidence.json` из релиза. Покажи несколько результатов, объясняя последовательность:

| Этап | Что сказать |
|---|---|
| Проработка задачи | «AI превратил описание в четыре проверяемых критерия приёмки». |
| Тесткейсы | «AI подготовил десять сценариев, включая ошибки, отмену и таймауты». |
| Спецификация | «AI описал решение, интерфейсы и допустимый список изменяемых файлов». |
| Реализация | «AI написал Go-код и тесты. Оркестратор запускал настоящие проверки и возвращал ошибки модели на исправление». |
| Подготовка PR | «AI подготовил описание изменений; Devflow обновил существующий draft PR». |
| Ревью | «Отдельный AI-запрос проверил diff по требованиям, спецификации и результатам тестов». |
| Релиз | «AI написал release notes. После одобрения проверенного SHA программа собрала и опубликовала выпуск». |

## 3. Контроль процесса — 45 секунд

Покажи `assets/skills` и `assets/invariants.json`:

> «Скиллы определяют инструкции для каждого этапа. Инварианты проверяются Go-кодом: нельзя пропустить этап, менять несогласованные файлы или выпустить другой коммит. AI выполняет содержательную работу, а оркестратор управляет переходами и проверками».

## 4. Реальные ошибки и результат — 45 секунд

Покажи PR и зелёный CI:

> «Один тест обнаружил, что ошибка команды могла раскрыть подставной секрет. AI исправил обработку ошибок. Дальше код прошёл анализ, тесты и сборку. Первые неудачные попытки тоже сохранены в артефактах».

Уточни роль человека:

> «Оператор восстановил API-баланс, слил PR после проверок и одобрил SHA для выпуска».

## 5. Живой запуск и релиз — 45 секунд

Запусти:

```bash
cd /Users/mili/Desktop/devflow
./bin/devflow doctor --env-file ../codex-chat-cli/.env
```

Покажи успешный ответ, затем страницу релиза:

> «Команда проверила реальное окружение и обратилась к AI API. Здесь опубликованы готовый бинарник, контрольные суммы и доказательства прохождения этапов».

Для финальной фразы:

> **«Проект решает мою реальную задачу автоматизации разработки. На защите я показываю уже выполненный запуск: полезную доработку самого Devflow — от требований до опубликованного релиза».**
